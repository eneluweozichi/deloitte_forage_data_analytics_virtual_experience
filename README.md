## Deloitte Australia – Data Analytics Virtual Experience

### Data Analytics | Tableau | Microsoft Excel | Data Visualization

**📌 Project Overview**

This repository showcases my work during the Deloitte Australia Data Analytics Virtual Job Simulation, completed through Forage.

The simulation provided practical exposure to real-world data analytics tasks, allowing me to apply analytical thinking, data interpretation, data visualization, and data-driven problem-solving to business scenarios.

Through this experience, I worked on data analysis and visualization tasks, exploring how data can be transformed into meaningful insights to support business decisions.

**🎯 Project Objectives**

The key objectives of this project were to:
- Apply data analytics techniques to business-related scenarios.
- Analyze and interpret datasets to identify meaningful patterns.
- Develop visual representations of data to communicate insights.
- Evaluate employee compensation equality using data classification.
- Demonstrate how data-driven insights can support organizational decision-making.
